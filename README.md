
# Data Analyst Job Market Analysis

This project explores trends in the data analyst job market using a dataset of over 2,000 job listings. It focuses on analyzing salary ranges, job locations, required skills, and company ratings to provide insights into current industry demands.

## Objectives

- Identify key factors influencing data analyst salaries.
- Analyze job location trends and popular hiring cities.
- Understand the most in-demand technical and soft skills.

## Tools & Technologies Used

- **Python**: Data wrangling and analysis (`pandas`, `numpy`)
- **Visualization**: `matplotlib`, `seaborn`
- **EDA**: Exploratory Data Analysis
- **Visual Studio**: Code development and analysis
- **Excel**: Initial data inspection

## Key Insights

- **Top cities**: New York, San Francisco, and Chicago lead in job availability.
- **High-demand skills**: SQL, Excel, Python, and Tableau dominate job descriptions.
- **Salary range**: Senior roles offered up to $120,000+ annually; entry-level roles started from $45,000.

##  Outcomes

- Created detailed visualizations to compare salary trends by city and role level.
- Highlighted important skills for aspiring data analysts.
- Supported career planning by identifying hiring hotspots and compensation benchmarks.
